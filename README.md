# reader (阅读3 服务器增强版)

> **声明**：本项目基于原开源项目 [hectorqin/reader](https://github.com/hectorqin/reader) 进行二次开发与构建维护。维护者非官方原作者，特此向原作者团队及相关开源贡献者致敬。

## 📖 项目简介

**reader** 是一款功能强大、体验舒适的**阅读 3.0 服务器版 Web 阅读器**。
无需依赖手机端 App，即可在浏览器、手机、平板、电视盒子、电子墨水屏 (Kindle) 等任意设备上畅享小说阅读，支持书源管理、在线并发搜书、进度多端同步与云端备份。

### 🌟 本分支全新特性与架构升级 (v2.0 正式版)

本项目在保留原版优秀能力的基础上，针对移动端沉浸体验、视觉排版、手势交互、高并发稳定性与文件存储安全进行了深度重构与全面升级：

1. 📖 **全新 3D 纸张拟真「仿真翻页」模式**：
   - 翻页方式升级为「上下滑动」、「左右滑动」、「仿真翻页」3 个标准选项。
   - 基于纯客户端 CSS 3D Transform（`perspective: 1600px`、`rotateY`、`transform-origin: left center`）打造高质感立体纸书翻折效果。
   - 正面翻转时背光阴影自然渐变，底层新页投射书脊阴影，翻过 90 度自动呈现纸张背面纹理，手势轻扫或点击即可触发，GPU 硬件加速超丝滑且**服务器资源占用为 0%**。

2. ✂️ **选词快捷气泡操作与自研选区高亮（彻底屏蔽系统原生菜单）**：
   - 在手机端长按或划选文字时，自动浮现【复制】、【添加书签】、【添加过滤规则】三合一轻量操作胶囊。
   - 采用自研独立半透明高亮层，**彻底屏蔽 iOS Safari 与 Android 浏览器自带的“拷贝/查询/翻译/搜索网页”系统弹窗**，界面纯净整洁。
   - 优化划选生命周期锁定与手势拦截，彻底解决长按选词时屏幕晃动跳跃、划选抬手误触发翻页跳到前一页、以及误触二次回弹等问题。

3. 📐 **阅读设置面板 3 标签等宽网格排版规范**：
   - 全面重构设置面板为弹性流式布局，所有选项统一遵循 3 标签等宽排版标准，彻底消除长短参差不齐与换行错位。
   - 特殊模式精简为「正常」、「简洁」、「边缘识别」，简洁说明仅在开启时动态浮现；精简配置方案为「内置白天」、「内置黑夜」、「自动切换」，彻底删除冗余的“方案类型”。

4. 🔤 **霞鹜“文楷”精品字体升级与默认启用**：
   - 正文字体标签升级为「文楷」，内置完整收录的 119 切片轻量化“霞鹜文楷”优质中文字形包。
   - 默认白天与黑夜阅读配置全面启用文楷，呈现如纸质出版物与微信读书级别的典雅舒适排版。

5. 📱 **仿安卓屏幕双边缘侧滑返回书架**：
   - 在设置中开启“边缘识别”后，在全屏无物理返回键的场景下，轻滑屏幕左边缘或右边缘即可呼出弧形指示器返回书架，内置双击防误触提示确认。

6. 🍏 **iOS 全面屏状态栏与灵动岛安全区深度避让**：
   - 引入 WebKit 安全区环境变量（`env(safe-area-inset-top)`），管理后台导航条、顶部标题栏与齐刘海/灵动岛彻底解耦，杜绝遮挡与触控失效。

7. 📚 **书架高并发安全与图书计数修复**：
   - **根除刷新书架书籍丢失与数量跳动**：重构 `getBookShelfBooks()` 内部协程写入机制，非刷新状态下直接顺序加载，零线程竞争并 100% 保持书架排序；在并发刷新章节状态下采用预分配槽位安全写入，彻底解决书架数量跳动、书籍随机变少的竞态问题。
   - **后台书源工具栏精简与 2 排等比栅格**：移除冗余的探索书源入口，将 6 个核心操作按钮（导入、远程、失效检测、调试、全部启用、全部禁用）在移动端组织为标准的 2 排栅格布局，自适应手机屏幕等比缩放。
   - **书架二级分类胶囊化横向滑动**：书籍管理、分组管理、导入书籍、浏览书仓、刷新缓存全面升级为平滑横向滑动的胶囊药丸（Pill Badges）导航。
   - **用户空间卡片排版防溢出重构**：修复“同步用户配置”卡片文字在手机窄屏上被挤出屏幕边缘的问题，改为自适应单列流式布局。

2. 🛡️ **无 DB 文件存储安全保障（彻底杜绝丢书架与进度丢失）**：
   - **原子写入与断电保护**：采用“临时文件写入 + 系统级原子替换（Atomic Move）”机制，杜绝断电、系统崩溃或容器重启导致 `shelf.json` / `bookSource.json` 损坏变为空文件的风险。
   - **高并发读写锁**：严格按文件路径建立进程内全局读写锁，多端同时翻页阅读、进度自动保存与后台追更任务并发时互不干扰，数据零竞争。

3. ⚡ **全链路分级超时体系与协程非轮询调度**：
   - **底层超时解耦**：将网络请求拆分为“握手超时（5 秒）”与“传输超时（12 秒）”，并关闭失效 IP 的自动死链重试，快速跳过僵尸站点，不占用连接池。
   - **业务场景分级超时**：搜书请求动态放宽至 6 秒（结合即时流式推送，国内极速源 0.8 秒首屏展现，海外优质源延后静默追加）；点选章节正文放宽至 15 秒并提供平滑加载提示，兼顾快慢书源。
   - **Channel 响应式消费**：移除旧版轮询等待机制，改用原生 Kotlin 协程通道队列驱动，任务完成即刻唤醒，CPU 零空耗。

3. 🎯 **书源熔断器原子化与防误杀策略**：
   - **线程安全指标**：熔断器健康度计数器全面原子化（Atomic），保障多任务高并发检索时统计绝对精准。
   - **误判隔离**：严格区分“正常返回 0 条书籍（冷门书）”与“网络超时/服务器故障”，搜冷门书绝不误杀优质书源；按响应耗时分梯队优先调用极速站点。

4. 🐧 **TTS 听书缓存 Docker / Linux 深度适配**：
   - 针对 Linux 内核与 Docker 容器存储驱动默认开启 `noatime/relatime`（文件读取不更新访问时间）导致的缓存误删问题，每次命中缓存主动刷新时间戳，恢复正统的 LRU（最近最少使用）淘汰逻辑。

5. 🐕 **Rhino JS 沙箱死循环看门狗**：
   - 为书源解析执行器注入指令计数器看门狗，当恶意或编写有缺陷的书源执行死循环、死正则时，超阈值自动强制击穿中断，守护后台 CPU 不被占满 100%。

6. 🔑 **Token 掉电持久化与云备份防爆内存**：
   - **登录态无感保活**：Token 映射持久化落盘，服务重启或镜像升级后，手机或电脑无需重新输入密码登录。
   - **云同步白名单防 OOM**：WebDAV 与 GitHub 云备份新增智能白名单，自动过滤章节正文缓存、TTS 音频与日志，仅打包核心配置与数据，彻底杜绝内存溢出。

7. 🎙️ **听书语音智能精简与优先级前置**：
   - **语音精简**：本地设备语音库自动过滤，只保留中文普通话、粤语及主流英语，界面清爽干净。
   - **本地优先**：本地低延迟高质量语音默认排在最前面并作为首选项，微软 Edge 在线语音排列在后，离线或在线皆可舒适畅听。

8. 📱 **手机端管理后台自适应响应式重构**：
   - 移动端视口专项优化，侧边栏自动变为顶部横向可滑动的胶囊式标签条。
   - 统计卡片与表单栅格由多列自适应折叠为单列流式布局，去除表格截断与文字挤压。
   - 对话框与操作按钮全面适配手机屏幕宽度，手指单手点按轻松自如。

9. 👥 **分权管理后台与密码加密云同步**：
   - **管理员控制台**：全站状态概览、配额治理、用户鉴权分配、WebDAV/GitHub AES 加密云同步与定时备份、诊断运行日志、全盘维护。
   - **普通用户专属子后台**：支持书源管理、失效源并发检测与一键清理、导入书源、一键同步管理员优质默认书源；支持书架书籍管理、在线修改封面、本地书仓浏览导入。
   - **免弹窗拟态全屏登录**：高质感磨砂毛玻璃卡片设计，支持自主注册策略与邀请码开关。

## 🚀 安装部署指南

### 方式一：Docker Compose 极速部署（推荐 🌟）

适合部署在 Linux VPS、云服务器或群晖/威联通/绿联/极空间等各类 NAS 设备上。

#### 1. 创建配置文件
在宿主机新建目录（如 `reader`），并在该目录下创建 `docker-compose.yml` 文件：

```yaml
services:
  reader:
    image: ghcr.io/mysecret2022/reader:latest
    container_name: reader
    restart: always
    ports:
      - "8080:8080" # 外部访问端口，按需调整（宿主机端口:容器端口）
    volumes:
      - ./storage:/storage # 数据持久化目录（书源、书架、用户数据、缓存及配置）
      - ./logs:/app/logs   # 日志输出目录（与管理后台诊断日志实时互通）
    environment:
      - TZ=Asia/Shanghai
      - SPRING_PROFILES_ACTIVE=prod
      - READER_APP_SECURE=true # 默认多用户鉴权模式（默认管理员：admin，默认密码：admin）
```

#### 2. 启动服务
在包含 `docker-compose.yml` 的目录下执行：
```bash
docker compose up -d
```
启动完成后，在浏览器访问 `http://<服务器IP>:8080` 即可进入登录界面。
- **默认管理员账号**：`admin`
- **默认管理员密码**：`admin`（首次登录后请在后台管理页面修改密码；邀请码可在后台「系统设置」中直接配置）

### 方式二：Docker 命令行一键运行

如果您习惯使用纯 Docker 命令：

```bash
docker run -d \
  --name reader \

  -p 8080:8080 \
  -v $(pwd)/storage:/storage \
  -v $(pwd)/logs:/app/logs \
  -e TZ=Asia/Shanghai \
  -e SPRING_PROFILES_ACTIVE=prod \
  -e READER_APP_SECURE=true \
  ghcr.io/mysecret2022/reader:latest
```

### 方式三：群晖 / 威联通 / 绿联 / 极空间 NAS 图形化部署

1. **拉取镜像**：在 NAS 的 Docker/Container 应用中搜索并拉取：
   `ghcr.io/mysecret2022/reader:latest`
2. **端口设置**：
   - 容器端口：`8080`
   - 本地端口：`8080`（或任意未占用端口）
3. **文件夹映射 (存储卷)**：
   - 本地 `docker/reader/storage` -> 容器内 `/storage`（或 `/app/storage`）
   - 本地 `docker/reader/logs` -> 容器内 `/app/logs`（或 `/logs`）
4. **环境参数添加**：
   - `TZ` = `Asia/Shanghai`
   - `SPRING_PROFILES_ACTIVE` = `prod`
   - `READER_APP_SECURE` = `true`
5. 点击创建并运行容器即可。首次使用 `admin / admin` 登录，所有权限、密码与配额直接在进入后台 `http://<NAS_IP>:8080/#/admin` 界面在线设置。

---

### 方式四：Java JAR 包直接运行 (Windows / Linux / macOS)

仅需环境安装 **Java 11 (JRE 或 JDK 均可)**：

1. 前往本仓库 [Releases 页面](https://github.com/mysecret2022/reader/releases) 或 GitHub Actions 下载最新的 `reader-2.0.0.jar`。
2. 在终端或命令行执行启动：

```bash
# 1. 简易自用模式（免登录）
java -jar reader-2.0.0.jar --reader.server.port=8080

# 2. 多用户安全模式（推荐）
java -jar reader-2.0.0.jar \
  --reader.server.port=8080 \
  --reader.app.secure=true \
  --reader.app.secureKey=你的管理员密码 \
  --reader.app.cacheChapterContent=true
```

#### Windows 一键启动脚本 (.bat)
在 `reader-2.0.0.jar` 同目录下新建 `启动阅读.bat`（请确保保存编码为 ANSI/GBK）：
```cmd
@echo off
chcp 936 >nul
title Reader 服务端
echo 正在启动 Reader 阅读服务器，请稍候...
java -jar reader-2.0.0.jar --reader.server.port=8080 --reader.app.secure=true --reader.app.secureKey=admin123456
pause
```
双击 `启动阅读.bat` 即可开机即用，浏览器打开 `http://localhost:8080`。

## ⚙️ 核心参数与环境变量说明

> **推荐说明**：多用户登录鉴权、管理员密码、注册邀请码、系统用户上限、章节高速缓存等均已支持在管理员后台（`http://<服务器IP>:8080/#/admin`）在线可视化调整，即时生效且自动持久化保存，无需在容器配置中手动指定。如有特殊需要可在启动时预设以下环境变量：

| 环境变量参数 | 命令行对应参数 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `READER_APP_SECURE` | `--reader.app.secure` | `true` | 是否开启多用户登录鉴权（默认为 `true` 开启强制登录） |
| `READER_APP_SECUREKEY` | `--reader.app.secureKey` | 无 | 初始系统管理员 `admin` 的密码（系统初次启动默认密码为 `admin`） |
| `READER_APP_INVITECODE` | `--reader.app.inviteCode` | 空 | 注册专属邀请码（后台可随时开关） |
| `READER_APP_USERLIMIT` | `--reader.app.userLimit` | `50` | 允许注册的最大用户数上限（后台可弹性调整） |
| `READER_APP_USERBOOKLIMIT`| `--reader.app.userBookLimit` | `200` | 单个用户书架最大收藏图书数量 |
| `READER_APP_CACHECHAPTERCONTENT` | `--reader.app.cacheChapterContent` | `true` | 是否在服务端本地缓存章节正文内容（默认为 `true`） |
| `READER_SERVER_PORT` | `--reader.server.port` | `8080` | 服务端监听端口号 |

## 🛠️ 数据目录结构说明

所有书架、书源、用户账户与缓存均保存在本地 `storage` 目录下（容器内挂载至 `/app/storage`）：
```text
storage/
├── assets/       # 自定义阅读背景图、个性化样式文件
├── cache/        # 搜索缓存与封面图片高速缓存
├── data/         # 用户书源、书架、加密配置与用户信息
│   ├── admin/    # 管理员个人书架与默认书源 (供全站用户一键同步)
│   ├── users.json# 用户鉴权与加密凭据数据库
│   └── systemConfig.json # 全局动态配置
└── localStore/   # 共享本地书仓（可存放 txt/epub/cbz 书籍，前台一键入架）
```
